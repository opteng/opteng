## Hi there 👋

I am a doctoral researcher in computational photonics at Karlsruhe Institute of Technology (KIT), working on inverse design of nanophotonic structures for tailored light scattering.

### Research project

My projects are visible on GitHub repository of my research group:

- [dreams](https://github.com/tfp-photonics/dreams/) - Differentiable T-matrix multiple-scattering framework developed in JAX.
- [T-matrix data format](https://github.com/tfp-photonics/tmatrix_data_format) -  Implementations, examples, and validation tools for a standardized hdf5 format for T-matrices.
- [ML with T-matrix data](https://github.com/tfp-photonics/tdat_ml) - Machine learning for forward and inverse problems using T-matrix data.
